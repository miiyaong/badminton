랜덤 경기 추천

일반 추천에서 남복·여복은 같은 성별의 서로 다른 두 묶음에서 각 2명을 뽑고, 혼복은 남자·여자 한 묶음씩에서 각 2명을 뽑습니다. 파트너 우선 추천에서는 등록한 두 사람을 같은 팀으로 묶고, 비슷한 실력의 상대 두 명을 찾습니다. 혼복 일반 추천 인원이 부족하면 같은 인접 그룹 번호의 남녀 네 묶음에서 각 1명을 뽑습니다. 예를 들어 남자 1 + 여자 2 대 남자 2 + 여자 1로 교차 편성하며, 1·3처럼 떨어진 그룹은 이 방식에서 제외합니다. 모든 추천은 종목별 성별 조건을 지킵니다.

대기(게임 가능)에 있는 묶음 지정 선수만 참여합니다. 1그룹이 가장 높은 실력이며 6그룹까지 순서대로 낮아집니다. 추천 버튼을 누를 때 50% 확률로 등록 파트너를 같은 팀으로 우선 추천합니다. 상대는 같은 그룹부터 찾고 부족하면 인접 그룹으로 넓힙니다. 나머지는 일반 랜덤 추천입니다.

버튼을 누르면 해당 종목의 후보를 최대 3개 생성합니다.

후보를 생성한 후 한 경기를 선택하면 빈 대기 칸에 들어갑니다.

파트너 관리

선수 한 명은 동성 파트너(남복 또는 여복) 1쌍과 혼복 파트너 1쌍을 각각 등록할 수 있습니다. 이름 뒤에 파트너별 이모티콘이 최대 2개 표시됩니다. 다른 쌍과 이모티콘이 겹치지 않도록 지정하세요.

파트너는 현재 위치나 묶음 지정 여부와 관계없이 등록할 수 있으며, 해제하거나 선수를 삭제하기 전까지 계속 유지됩니다. 휴식·경기·게임 대기 중에도 이모티콘이 유지됩니다. 실제 랜덤 추천에만 두 사람이 모두 게임 가능 대기에 있고 묶음과 성별이 지정되어야 합니다. 남자끼리는 남복, 여자끼리는 여복, 남녀 파트너는 혼복에 참여합니다.

추천 버튼을 누를 때마다 한 번만 50% 추첨하며, 생성되는 후보들은 같은 추천 방식을 사용합니다. 여러 쌍이 가능하면 쌍을 무작위로 고릅니다. 파트너 추천 조건이 맞지 않으면 일반 추천을 사용합니다. 일반 추천에서도 우연히 같은 팀이 될 수 있으므로 실제 같은 팀 비율이 정확히 50%인 것은 아닙니다.

파트너가 3·4그룹이면 상대도 3·4그룹 조합을 최우선으로 찾습니다. 부족하면 가까운 2·5그룹을 포함하고, 그래도 부족하면 1·6그룹까지 넓힙니다. 같은 그룹 파트너도 등록할 수 있습니다. 이모티콘을 변경하려면 해제 후 다시 등록하세요.
